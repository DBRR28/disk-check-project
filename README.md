# Disk Usage Check Project

A simple Bash script that monitors disk usage on a Linux server.

## What It Does

- Checks the disk usage of the server
- Displays the current disk usage percentage
- Shows a warning if disk usage goes above 80%

## Technologies Used

- AWS EC2
- Ubuntu Linux
- Bash
- Git
- GitHub

## Run the Script

```bash
chmod +x disk-check.sh
./disk-check.sh
